# dev-team

Скилл для Codex, который организует разработку через специализированных субагентов: исследователя, разработчика и независимого ревьюера. Объём проверок выбирается по риску изменений — от просмотра diff до целевых интеграционных и сквозных сценариев.

## Что делает

- подключает исследователя для сложной неопределённости и архитектурных вопросов;
- передаёт разработчику проверяемый бриф с ожидаемым поведением и критериями готовности;
- проверяет исправление бага по исходному сценарию с результатами до и после;
- всегда проводит независимое ревью требований и качества реализации, включая незакоммиченные изменения;
- выбирает проверки по уровням риска R0–R3;
- возвращает компактный отчёт о результате, тестах и оставшихся ограничениях.

Скилл запускается только явно: через `$dev-team` или прямую просьбу использовать этот навык.

## Установка

Скопируйте каталог репозитория в папку пользовательских скиллов Codex:

```bash
git clone https://github.com/epolevov-nsp/dev-team.git ~/.codex/skills/dev-team
```

После установки перезапустите Codex, чтобы новый скилл появился в списке доступных.

## Использование

```text
Используй $dev-team для этой задачи: реализуй изменения и поручай отдельному ревьюеру проверки по риску.
```

Основные инструкции находятся в [`SKILL.md`](SKILL.md), политика тестирования — в [`references/testing.md`](references/testing.md).

## Совместимость

Скилл рассчитан на Codex с поддержкой субагентов и доступом к моделям, указанным в `SKILL.md`. Если конкретная модель недоступна, оркестратор должен явно сообщить об этом и не имитировать делегирование.
